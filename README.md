### 🚀 Featured projects

**[Orion 2WD Robot](https://github.com/JoaoFranciscoCSantos/Orion-2WD-Robot)**
A two-wheel-drive robot built on a NodeMCU ESP8266, with a TB6612 motor driver and N20 motors. It has web control over WiFi, an SPI TFT display and QTR-8RC sensor support. Line following, obstacle detection and vision are on the roadmap.
`Robotics` `Embedded` `ESP8266` `WiFi`

**[SVG to PNG Converter](https://github.com/JoaoFranciscoCSantos/svg_to_png)**
A C++ tool that parses SVG files (using TinyXML2) and renders them to PNG, with support for geometric shapes and transformations. Group project focused on XML parsing, geometry, and collaborative Git workflows.
`C++` `TinyXML2` `Parsing` `Geometry`

**[Wishlist App](https://github.com/JoaoFranciscoCSantos/wishlist-app)**
A wishlist web app with a savings tracker and purchase suggestions based on a knapsack algorithm (priority + price). Paste a product link and it extracts the name, price and image automatically. Built from scratch with Flask and SQLite, with a mobile version planned.
`Python` `Flask` `SQLite` `Web Scraping`

**[Price Scout](https://github.com/JoaoFranciscoCSantos/price-scout)**
A price tracker that follows an item across multiple online stores to find the lowest price. It combines scraping with official APIs (eBay Browse API), keeps the full price history and supports multiple currencies. Covered by a pytest suite.
`Python` `SQLite` `APIs` `pytest`

**[Agenda AI](https://github.com/JoaoFranciscoCSantos/agenda-ai)** *(in progress)*
A personal scheduling app with a custom scheduler: conflict detection, free-slot search and automatic task scheduling. PostgreSQL backend, repository layer and tests, with a TUI and AI-powered suggestions planned.
`Python` `PostgreSQL` `Testing` `Algorithms`
